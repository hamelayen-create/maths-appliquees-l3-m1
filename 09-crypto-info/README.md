# 09 — RSA pédagogique, entropie et code de Hamming

**Niveau :** L3  
**Maths :** arithmétique modulaire, entropie de Shannon, codes correcteurs

## Contenu

- RSA pédagogique (petites clés, usage éducatif uniquement)

- Code de Hamming (7,4) : encodage / correction 1 bit

> Avertissement : l'implémentation RSA est **pédagogique** (pas de sécurité réelle).
