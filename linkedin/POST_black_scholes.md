## Texte du post

J’ai publié un projet de maths appliquées L3/M1 sur le pricing Black–Scholes.

L’idée n’était pas juste “recoder une formule”.
C’était de montrer qu’**un même prix d’option** peut être obtenu de 3 façons indépendantes :

1. formule fermée  
2. résolution d’EDP (Crank–Nicolson)  
3. Monte Carlo (avec réduction de variance)

Sur un call ATM standard, les trois méthodes tombent sur le même ordre de grandeur — et les écarts s’expliquent (biais numérique, variance, grille).

Ce que j’ai mis dans le dossier :
- un rapport pédagogique (~15 pages)
- du code Python testé
- des figures de convergence et des Grecs
- le lien théorie ↔ implémentation

Ce projet fait partie d’un monorepo de 9 sujets (finance, physique, informatique) : Markowitz, smile SVI, EDP chaleur/ondes, Schrödinger, PageRank, ML from scratch, etc.

Si tu es en école / fac / reconversion quant-data, le repo est open source.
