# 04 — Oscillateurs, résonance et systèmes dynamiques

**Niveau :** L3  
**Maths :** EDO, espace de phase, Fourier, bifurcation (Duffing)

## Problème

Étudier
- l'oscillateur harmonique amorti / forcé ;
